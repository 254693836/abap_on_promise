# SAP ABAP ファイル入出力デモプログラム 開発要件

## 1. 開発目的

SAP S/4HANA上で動作するABAP Executable Report Programを作成してください。

指定されたINPUTファイルを読み込み、
その内容をOUTPUTファイルへ出力するデモプログラムとします。

以下の2種類のファイル処理を実装してください。

1. ローカルPC上のファイル
2. SAPアプリケーションサーバー上のファイル

Selection ScreenのRADIOBUTTONによって、
LOCAL処理とSERVER処理を切り替えられるようにしてください。


## 2. 成果物

・実装言語：ABAP
・プログラム種別：Executable Report Program
・ソースコード保存先：Z_087_OPENDATASET_DEMO.txt
・対象SAP環境：S/4HANA
・コード内のコメント：日本語


## 3. Selection Screen

Selection Screenに以下の項目を配置してください。


### 3.1 処理方式

RADIOBUTTONで以下のどちらかを選択できるようにしてください。

○ LOCAL
○ SERVER

LOCAL：
ユーザーPC上のファイルを処理する。

SERVER：
SAPアプリケーションサーバー上のファイルを処理する。

どちらか一方のみ選択可能としてください。


### 3.2 INPUTファイル

INPUTファイルのパスを入力する項目を作成してください。

例：

INPUTファイル：
[________________________________]


### 3.3 OUTPUTファイル

OUTPUTファイルのパスを入力する項目を作成してください。

例：

OUTPUTファイル：
[________________________________]


## 4. 共通処理

処理の基本的な流れは以下としてください。

① LOCAL / SERVERを判定
↓
② INPUTファイルの存在確認
↓
③ INPUTファイルを読み込む
↓
④ 読み込んだ内容を内部テーブルへ格納
↓
⑤ OUTPUTファイルへ書き込む
↓
⑥ 処理結果を表示


## 5. INPUTファイル

指定されたINPUTファイルを読み込んでください。

ファイルはテキストファイルを対象とし、
基本的に1行ずつ読み込んで内部テーブルへ格納してください。

INPUTファイルが存在しない場合は、
エラーメッセージを表示して処理を中止してください。

エラー例：

「INPUTファイルが存在しません。」

INPUTファイルが存在しない場合、
OUTPUTファイルは作成しないでください。


## 6. OUTPUTファイル

INPUTファイルから読み込んだ内容を、
指定されたOUTPUTファイルへ書き込んでください。

OUTPUTファイルが存在しない場合は、
新規作成してください。

OUTPUTファイルがすでに存在する場合は、
既存内容を上書きしてください。

INPUTファイルと同じ内容が
OUTPUTファイルに保存されるようにしてください。


## 7. LOCALファイル処理

LOCALを選択した場合は、
ユーザーPC上のファイルを処理してください。

OPEN DATASETは使用せず、
SAP GUIのフロントエンドファイル操作に適した標準機能を使用してください。

例：

・CL_GUI_FRONTEND_SERVICES=>FILE_EXIST
・CL_GUI_FRONTEND_SERVICES=>GUI_UPLOAD
・CL_GUI_FRONTEND_SERVICES=>GUI_DOWNLOAD

必要に応じて、
INPUT / OUTPUTファイル選択用のファイルダイアログも実装してください。


## 8. SERVERファイル処理

SERVERを選択した場合は、
SAPアプリケーションサーバー上のファイルを処理してください。

以下のABAP構文を使用した実装例を含めてください。

・OPEN DATASET
・READ DATASET
・TRANSFER
・CLOSE DATASET


### INPUTファイル

基本的な処理イメージ：

OPEN DATASET <input_file> FOR INPUT IN TEXT MODE ...

READ DATASET <input_file> INTO ...

CLOSE DATASET <input_file>


### OUTPUTファイル

基本的な処理イメージ：

OPEN DATASET <output_file> FOR OUTPUT IN TEXT MODE ...

TRANSFER ...

CLOSE DATASET <output_file>


OUTPUTファイルが存在しない場合は、
OPEN DATASET FOR OUTPUTによって新規作成してください。

既存OUTPUTファイルが存在する場合は、
上書きする仕様としてください。


## 9. ファイル存在チェック

LOCALとSERVERでは適切な方法を使い分けてください。

LOCAL：
フロントエンド用の標準クラス・標準APIを使用する。

SERVER：
アプリケーションサーバー上のファイルとして確認する。

INPUTファイルが存在しない、
またはOPENできない場合は、
エラーとして処理してください。


## 10. エラー処理

少なくとも以下のエラーを考慮してください。

・INPUTファイルが存在しない
・INPUTファイルをOPENできない
・INPUTファイルを読み込めない
・OUTPUTファイルを作成できない
・OUTPUTファイルへ書き込めない
・ファイルへのアクセス権限がない

エラー発生時は、
可能な範囲で具体的な日本語メッセージを表示してください。

SERVER処理では、
OPEN DATASET等の実行後にSY-SUBRCを確認してください。


## 11. 処理結果

正常終了した場合は、
以下の情報を表示してください。

・処理方式：LOCAL / SERVER
・INPUTファイル名
・OUTPUTファイル名
・読み込み行数
・書き込み行数
・処理結果

例：

処理方式       ：SERVER
INPUTファイル  ：/tmp/input.txt
OUTPUTファイル ：/tmp/output.txt
読み込み行数   ：100
書き込み行数   ：100
処理結果       ：正常終了


## 12. プログラム構造

処理内容が理解しやすいように、
LOCALとSERVERの処理をFORMで分離してください。

例：

START-OF-SELECTION.

  IF p_local = abap_true.
    PERFORM process_local.
  ELSEIF p_server = abap_true.
    PERFORM process_server.
  ENDIF.


FORM process_local.
  " ローカルファイル処理
ENDFORM.


FORM process_server.
  " アプリケーションサーバーファイル処理
ENDFORM.


必要に応じて、さらに以下のようなFORMへ分割してください。

・read_local_file
・write_local_file
・read_server_file
・write_server_file
・display_result

## 14. 実装上の注意事項

・S/4HANAで利用可能な標準ABAPを使用すること
・LOCALとSERVERのファイル処理を明確に分離すること
・INPUTファイルが存在しない場合は処理を中止すること
・INPUTファイルが存在しない場合はOUTPUTファイルを作成しないこと
・OUTPUTファイルが存在しない場合は新規作成すること
・OUTPUTファイルが存在する場合は上書きすること
・ファイルはTEXT MODEで処理すること
・ファイルをOPENした場合は必ずCLOSEすること
・各処理のSY-SUBRCを適切に確認すること
・主要な処理には日本語コメントを記述すること
・学習用デモとして、処理をできるだけ分かりやすく記述すること
